# HackMol 7

A modern hackathon website built with Next.js for the seventh edition of HackMol, featuring information about tracks, speakers, sponsors, and event timeline.

## About

HackMol 7 is a technology hackathon that brings together developers, designers, and innovators to create meaningful solutions. This website serves as the central hub for event information, registration, and updates.

## Features

- Event information and timeline
- Speaker profiles and sessions  
- Competition tracks and prizes
- Sponsor showcase
- FAQ section
- Responsive design

## Technology Stack

- Next.js 14 with App Router
- TypeScript
- CSS Modules
- ESLint configuration

## Getting Started

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser

## Development

The project structure includes:
- `src/app` - Main application pages and layouts
- `src/components` - Reusable UI components
- `public` - Static assets including images and fonts

## Build

To create a production build:
```bash
npm run build
```
