# HackMol 7

A clean and modern website for the seventh edition of HackMol, designed to provide all important event details in one place.

## About

HackMol 7 is a hackathon that brings together developers, designers, and innovators to build impactful solutions.
This website acts as the central hub for announcements, registrations, and event updates.

## Features

* Event overview and timeline
* Speaker and session information
* Hackathon tracks and prizes
* Sponsor highlights
* FAQ section
* Fully responsive layout
